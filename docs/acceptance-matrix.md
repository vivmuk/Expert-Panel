# Feature acceptance matrix

Classes: **live** means a public GET in this hardening run. **mock** means a local test with a provider double. **unverified** means the code exists and this run did not observe the provider or the channel. **planned** means not built. A mock does not verify Venice, Exa, Supermemory, or Keiki.

| Surface | Class | Evidence |
|---|---|---|
| `/chat` page and job (intake, research, 20 experts, debate, judge, chart, kit) | mock, page live | `tests/test_chatjob.py`. `GET /chat` 200 and the free-engagement sentence. No live model call in this run. |
| Paid-call gate | mock, closed | `server/spendguard.py` and `tests/test_spendguard.py`. Tested unpaid intake stays open. Tested paid routes refuse before a provider call. A configured integer does not open them. Authorized v1 and MCP can return HTTP 200 with the refusal in the body. A signed Keiki turn can return HTTP 202 and put the refusal in the callback. |
| $5 project ledger | mock, not runtime enforcement | `server/projectbudget.py` and `tests/test_projectbudget.py`. 5000000 microusd is application accounting, not a provider bill, and not an engagement-attempt cap. Reuse requires the same service, stage, and input fingerprint. An uncertain step blocks a new step until reconcile and does not release its reservation. Facts are write-once. Report ids are random row ids, not hashes of caller text. An older ledger layout is refused and its rows are left in place. Two threads on one file cannot cross the ceiling. A valid snapshot restore, a copied file, and a new file after deletion are tested as unsolved holes. HTTP stays closed. Missing bills stay null. There is no cost URL for a partner key. |
| Engagement exposure | mock, HTTP closed | `server/exposure.py` and `tests/test_exposure.py`. One execution covers Venice, Exa, memory, voice, and image. Venice upstream tries are inside that reservation. A fourth execution stops before the offline transport. An uncertain execution blocks the next one and keeps its reservation. A caller-chosen project or execution id does not mint a budget. Two in-process authorities are not one cap. HTTP stays closed and there is no cost URL. This is not a provider invoice cap. |
| Same-browser project list | mock storage, page markup | `server/static/history.js` schema 3 stores job state without shortening fields, up to 2,000,000 characters. `tests/test_history.js` covers a long engine-shaped round trip, a refused oversize write, unreadable bytes left in place, two tabs on one storage, quota failure that does not claim a save, and a transcript that keeps null and wrong-shaped entries. The chat page keeps that open transcript when New or a project change cannot save, and it still renders the page. `GET /chat` includes the list and the recovery control. Not a server history and not per-person isolation on a shared browser. |
| `/connect`, `/get-started.md`, `/signup`, `/llms.txt`, `/skills.zip` | live page, mock signup | Public GETs. `tests/test_onboard.py` mints a key locally. Signup was not called on the hosts. |
